## 🌟 About The Project

Developing a clean, scalable, and responsive web interface is crucial for modern websites and e-commerce. This project serves as a comprehensive multi-page website template specifically tailored to showcase products, services, and corporate identity while providing a seamless user experience.

**Why this project stands out:**
*   **Semantic SEO:** Employs semantic HTML5 for enhanced search engine optimization and digital accessibility.
*   **Responsive:** Uses modular CSS3 for fluid, tailored layouts across all devices (Mobile, Tablet, and Desktop).
*   **Interactive:** Incorporates Vanilla JavaScript to handle dynamic components, including a fully interactive shopping cart.
*   **Lightweight:** No heavy frameworks are used—ensuring blazing fast load times and clean code.

### ✨ Key Features

- **5 Fully Responsive Pages:** `Home`, `About`, `Services`, `Shop`, and `Contact`.
- **Functional Shopping Cart Dashboard:** Users can add products, update quantities, and view their totals seamlessly via `cart.js`.
- **Modern UI/UX:** Clean typography, smooth hover effects, and a highly polished visual hierarchy.
- **Form Integration Ready:** Well-structured contact and inquiry forms ready to be plugged into any backend service.

## 🚀 Getting Started

To get a local copy up and running locally, follow these simple steps.

### Prerequisites

You will need a modern web browser and optionally a local development server for the best experience.
* Recommended Browser: Chrome, Firefox, Brave, or Edge.
* Code Editor: **VS Code** with the *Live Server* extension installed.

### Installation

1. Clone the repository
   ```sh
   git clone https://github.com/VadsolaKishan/Multi-Page-Website.git
   ```
2. Navigate into the project directory
   ```sh
   cd Multi-Page-Website
   ```
3. Open `index.html` in your browser, or start your Live Server to view changes in real-time.

## 📂 Project Structure

```text
├── assets/
│   ├── icons/            # SVG icons and web graphics
│   └── images/           # High-res photography & product images
```
